# Inference history

The Stream and Settings screens link to a live newest-first list of the last 100 mobile-originated inference attempts. Route selection, local native start, socket send and final completion are distinct. Desktop completion is recorded only on a decrypted/authenticated nonempty translation. Failed desktop attempts and subsequent phone attempts are separate rows. Phone PLaMo entries include the requested acceleration profile and reason for selecting local inference. FunctionGemma proposal, selection and resolution record individual generation calls; protocol validation is separate. Counts describe this bounded history, not lifetime totals. Cached translations do not count as requests.

History is retained locally in app preferences and a bounded diagnostics/inference-history.jsonl snapshot, exported by export-android.cmd. No captured text, generated response, key, SSID or network fingerprint is recorded in this history. Connection failures may include the configured desktop LAN URL and resolved socket address for diagnosis. No extra network messages, timers or host probes. The view subscribes to request events when visible; after a process restart previously active rows are marked interrupted. Clearing history removes completed rows; an active attempt may subsequently complete and appear again. Old lifecycle logs are not imported. Desktop activity initiated by other clients is not included.
