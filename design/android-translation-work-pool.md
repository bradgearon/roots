# Android translation work pool

Visible author names and body text have separate discovery and presentation roles. Author details use the original name and cached translation in the left-side details control; translated bodies use the right-side expansion control. The existing language hints remain in use. The live coordinator retains up to 256 discovered items for up to 120 seconds since their last observation while X stays foreground. The cache holds 512 completed translations in memory. Current discoveries receive a priority boost, with a reading-order bias; older work retains positive weight and gains bounded age priority. Provider admission still honors the user's 1–4 outstanding request limit. No native concurrency is added.

This is a foreground, in-memory scheduling layer, not the durable Tree worker integration. It does not read unexposed or previously invisible nodes, automatically scroll, process backlog after leaving X, or distribute work between local CPU, GPU and desktop simultaneously. Existing consent and transport selection remain unchanged. Native CPU/GPU parallel execution requires independent backend contexts, resource limits, correct-output validation and device benchmarks.
