# Accessible Garden listening journeys

Status: proposal; not implemented. Complements Garden participation and the portable knowledge design.

A user-approved journey specifies ordered sources and destinations, reading duration/post budget, language mode, content rules, original/translation preference, optional cognitive context, interruption policy and completion behavior. Garden Radio is a native audio-first experience that can read queued eligible content even when locked. It complements TalkBack and braille rather than replacing them.

LauncherService opens supported applications/deep links during an explicitly initiated foreground session. Browsing adapters expose capabilities: native/authorized API pagination, browser DOM observation, accessibility scroll actions on supported surfaces. Deterministic state machine: launch -> await surface -> observe -> dedup -> queue -> narrate -> advance when low watermark -> switch source -> complete. On uncertain UI, focus loss, unsupported surface, block or user stop, fail safely. No automatic unlocking, permission bypass or AI-directed arbitrary accessibility automation. Screen-off reads only already permitted queued content or authorized background-accessible sources. Verify store policies and source terms before release.

Narration uses semantic content (author, source, original, translation, alt text, permitted replies, labels), accessible native controls, predictable focus, TTS speed/voice, media session, audio focus and Bluetooth controls. Separate source text from model-derived descriptions and cognitive commentary. Prefer installed offline system TTS initially, optional licensed local models later. User can skip/pause/repeat/read original/save/stop via accessible controls; voice command parser proposes typed actions, public actions require confirmation. Prevent duplicate TalkBack announcements. Scheduled editions are user-configured subject to OS limits; no guaranteed unattended app launch.

Knowledge graph may supply eligible discoveries as labeled organic recommendations, distinct from paid sponsorships, with provenance and source resolution. Reading does not equal approval or consent to upload; local observation and shared cognition have separate policies. Never silently replace third-party content or obscure its origin.

Acceptance: complete a native journey without sight; verify with blind/low-vision participants and TalkBack; no rereading recycled posts; safe stopping; test lock-screen playback, source failures and denied permission; use one supported deterministic foreground source adapter before expanding. Keep translation regression tests. Measure time to first speech, underruns, battery/thermals, model residency and inference latency on target phone and desktop.
