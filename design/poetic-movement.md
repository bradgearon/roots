# Poetic Movement lab
An experimental two-call FunctionGemma 270M pipeline, not automatic social-data processing. The existing local Q8 model is used for both calls to measure whether it can perform selection and short poetic resolution. No additional model download is required if FunctionGemma is already installed.
1. A 128-bit SecureRandom seed (editable, displayed) deterministically ranks separate noun and verb banks with HMAC-SHA256. Twelve words from each bank are offered. Request 1 selects five distinct indexed pairs and supplies the ordinary action for each noun.
2. A fresh native context receives only those five pairs, their ordinary actions, and a short profile. Request 2 replaces the ordinary action and resolves the displacement in one short poetic sentence per pair. Optional self-rating is part of the same call, not independent evaluation.
No retries, no automatic Tree writes or sharing. Invalid syntax or out-of-range selections fail visibly. First-stage failure stops before request 2. The native function generation cap is raised to 384 tokens for resolution only; the ordinary proposal cap remains 160. Rebuild the cached brain after this native change.
Seed reproducibility applies to candidate lists, not guaranteed model output across model/runtime versions. This uses the platform cryptographic primitives, not yet a verified Forge-specific cryptographic interface. Model self-ratings are not a substitute for human judgment.
