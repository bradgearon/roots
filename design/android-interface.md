# Android Roots interface

The launcher is the Stream activity; Settings is the other primary destination. The Stream queries real native Tree fragments, newest first, with search, explicit paging, total count and separate capture opt-in. It refreshes on return or on demand. Tree of Life remains reachable as an existing utility. No demo posts, invented author metadata, translation progress or engagement counts are shown. The Tree currently retains original body fragments, source, optional external ID, language hint and observed timestamp. Overlay translations are not persisted into this feed yet.

Settings uses grouped collapsible cards and a shared dark native theme with readable controls and system insets. Existing model, connection, consent, scheduling, diagnostics and Tree controls remain. No new collection scope or network transmission is introduced.
